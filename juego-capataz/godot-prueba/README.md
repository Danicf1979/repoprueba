# Prueba en Godot 4.3

La misma escena que la versión web (un trono de palio en una calle de noche, con público), hecha con formas igual de simples, para comparar solo lo que aporta el motor: iluminación global (SDFGI), niebla volumétrica, sombras de cada farol, reflejos en pantalla, oclusión ambiental y resplandor.

Abre la carpeta con Godot 4.3 (Forward+) y ejecuta: el script `main.gd` monta la escena, saca tres capturas (`godot_frente.png`, `godot_detras.png`, `godot_lado.png`) y se cierra.
