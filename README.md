# repoprueba

Repositorio de trabajo organizado por temas: cada tema tiene su propia carpeta con un `README.md` que explica su contenido.

## Temas

| Carpeta | Contenido |
|---|---|
| [gestion-documentacion](gestion-documentacion/) | Guía de estudio de gestión de la documentación |

## Cómo trabajamos

- **Una carpeta por tema.** Nombres en minúsculas, con guiones, sin tildes ni espacios.
- **Markdown (`.md`)** para los textos, así GitHub los muestra con formato.
- **Una rama por tarea** (por ejemplo `gestion-doc/tema-3`); se une a `master` mediante Pull Request.
- **Commits con el tema delante**, por ejemplo: `gestion-doc: añade apartado de trabajo en local`.
